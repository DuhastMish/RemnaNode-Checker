Запуск на машине чекера

Образ собирается из папки agent/ репозитория: docker build -t {{ image }} agent/

docker run -d --name nodecheck-agent --restart unless-stopped \
  -e PANEL_URL={{ panel_url }} \
  -e CHECKER_TOKEN={{ new_token }} \
  {{ image }}

или фрагмент для docker-compose.yml:

services:
  agent:
    build: ./agent
    container_name: nodecheck-agent
    restart: unless-stopped
    environment:
      PANEL_URL: {{ panel_url }}
      CHECKER_TOKEN: {{ new_token }}

Чекер на одной машине с панелью: PANEL_URL=http://127.0.0.1:8000 и --network host.
